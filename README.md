# wordle-solver
Solves  Wordle

I keep hearing from people about how Claude-created code is so great. The project I am working on is pretty complex. Now, my family is full of Wordle addicts, so I asked Claude the following:

Please write a program in Python that solves Wordle.  It prints out a word, and in response it expects the user to input 5 characters.  eg. B.b*!   ,  The capital B means a green hit in Wordle, and the small b means a yellow hit and the other characters means unknowns. It complains if not exactly 5 characters are input, and it takes any prntable characters. You need to find a source of 5-letter words that is available on the internet that it can access.
